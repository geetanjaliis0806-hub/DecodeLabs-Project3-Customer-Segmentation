# Customer Segmentation using K-Means

## About the Project

This project focuses on understanding customer behavior and grouping customers with similar characteristics using Unsupervised Machine Learning.

I worked with retail customer data and used **PCA and K-Means Clustering** to identify meaningful customer segments. After clustering, I translated the results into simple customer personas and business strategies.

This project was completed as **Project 3 during my Data Science Internship at DecodeLabs**.

## What I Worked On

- Data cleaning and missing value handling
- Exploratory Data Analysis (EDA)
- Categorical feature encoding
- Feature scaling using StandardScaler
- PCA for dimensionality reduction
- Elbow Method for cluster analysis
- Silhouette Score for selecting the optimal K
- K-Means clustering
- 2D and 3D cluster visualization
- Customer persona analysis
- Business decisions and improvement strategies

## Dataset

The dataset contains **1,200 customer records** with 25 features covering areas such as:

- Customer demographics
- Income and spending
- Purchase frequency
- Website and app activity
- Discounts and coupons
- Loyalty points
- Returns
- Customer engagement
